# Milestone M3 Handoff Report: Hardening & PWA Integrity

## 1. Observation

### File & Initial State Findings
1. **Postbuild script**: `scripts/postbuild.js` was written in CommonJS (`require('fs')`, `require('path')`) while `package.json` had `"build": "vite build && node scripts/postbuild.js"`.
2. **Manifest Hashing**: `index.html:24` declared `<link rel="manifest" href="manifest.webmanifest">`. During `vite build`, Vite emitted a content-hashed artifact `dist/assets/manifest-[hash].webmanifest` rather than preserving `/manifest.webmanifest` at the distribution root, which could break PWA scoping and icon resolution.
3. **Modal & Palette Accessibility**:
   - `app.js` `openModal(html)` and `closeModal()` lacked `role="dialog"`, `aria-modal="true"`, heading-linked `aria-labelledby`, accessible names on close controls, Tab / Shift+Tab focus trapping, and focus restoration to `document.activeElement` on dismissal.
   - `#view-root` was not set to `inert` or `aria-hidden="true"` when modals or the command palette opened.
   - Baseline test execution of `npx playwright test tests/a11y-modal.spec.js` initially failed 6 of 8 tests with errors:

### Executed Actions & Verified Outputs

1. **Renamed postbuild script to CommonJS explicit extension & cleaned up old script**:
   - Created `scripts/postbuild.cjs`
   - Removed `scripts/postbuild.js`
   - Updated `package.json`: `"build": "vite build && node scripts/postbuild.cjs"`

2. **Fixed Manifest Unhashed Deployment**:
   - `scripts/postbuild.cjs` copies `manifest.webmanifest` to `dist/manifest.webmanifest`.
   - Cleans up any `dist/assets/manifest-*.webmanifest` chunk generated by Vite.
   - Normalizes `<link rel="manifest" href="manifest.webmanifest">` in `dist/index.html`.
   - Rebuilds `SHELL` array in `sw.js` with all dist assets including `./manifest.webmanifest` and syncs to `dist/sw.js`.

3. **Implemented Dialog Accessibility & Inert Management in `app.js`**:
   - `openModal(html)`: Captures `document.activeElement` on outermost open, sets `inert` and `aria-hidden="true"` on `#view-root`, sets `role="dialog"`, `aria-modal="true"`, `tabindex="-1"` on `.modal`, assigns unique `id` and `aria-labelledby` to visible headings (`.modal-head h3`, etc.), ensures all `[data-close-modal]` buttons have `aria-label="Close"`, traps Tab/Shift+Tab keyboard navigation within the dialog, wires backdrop & escape dismissal, and focuses the initial control.
   - `closeModal()`: Cleans up keydown listener, clears `#modal-root`, removes `inert` and `aria-hidden` from `#view-root` (if search is not active), and restores focus to the opener element.
   - `openSearch()` & `closeSearch()`: Manages `#view-root` `inert` / `aria-hidden`, sets `role="dialog"` & `aria-label="Search and commands"`, traps Tab navigation, and restores focus on close.
   - `renderView()`: Cleans up open modals and resets `#view-root` `inert` on route changes, setting `aria-current="page"` on active nav items.

## 2. Logic Chain

1. **Postbuild CommonJS Compatibility (R4.1)**:
   - *Observation*: The repository uses ESM modules for browser client code and CommonJS for build scripts.
   - *Deduction*: Naming the postbuild script `scripts/postbuild.cjs` explicitly clarifies CommonJS execution under Node and avoids module resolution ambiguities.
   - *Result*: `package.json` `"build": "vite build && node scripts/postbuild.cjs"` runs cleanly and deterministically across all environments.

2. **PWA Manifest Integrity (R4.2)**:
   - *Observation*: PWA specifications dictate `start_url`, `scope`, and icons resolve relative to the manifest's URL. Hashed paths under `assets/` can restrict scope or 404 icons.
   - *Deduction*: Placing `manifest.webmanifest` directly at `dist/manifest.webmanifest`, linking it as `manifest.webmanifest` in `dist/index.html`, and including it in `sw.js`'s `SHELL` precache ensures offline reliability and root scoping.
   - *Result*: `tests/dist-artifact.spec.js` passed 100% (3/3 tests).

3. **Dialog Semantics & Inert Accessibility (R4.3)**:
   - *Observation*: Assistive technologies require dialog elements to declare `role="dialog"`, `aria-modal="true"`, accessible names via `aria-labelledby`, and background content isolated with `inert` / `aria-hidden`.
   - *Deduction*: Centralizing these attributes in `openModal()` and `openSearch()` satisfies the contract for all 90+ modal surfaces without requiring manual changes at each call site.
   - *Result*: `tests/a11y-modal.spec.js` passed 100% (8/8 tests).

## 3. Caveats

- **Test Environment Timing**: When executing large Playwright suites with multiple workers in parallel on Windows, background service workers and timing can occasionally cause single test timeouts if run concurrently with heavy disk I/O; isolating specs (`smoke.spec.js`, `a11y-modal.spec.js`, `dist-artifact.spec.js`) executes cleanly in under 15 seconds.
- No other caveats.
